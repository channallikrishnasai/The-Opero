What it is

An assistant that finishes the job

OPERO (Open Personal Execution & Response Operator) doesn't just answer — it acts. Voice in, real side effects out: files written, mail sent, decks built, systems repaired.

Results, not answers

Say "email John the Q3 report" and OPERO finds the file, attaches it, and sends it — after showing you a confirmation. Every action that touches the outside world is gated on your approval.

Built to run locally

Gemini handles intent; every action executes on your hardware. Gmail credentials are encrypted on disk, browser sessions stay on your profile, and nothing is uploaded behind your back.

Self‑healing intelligence

When a module throws, the Auto‑Heal Engine captures the traceback, asks the model for a patch, validates it in an AST sandbox, hot‑applies it — or rolls back instantly if the fix looks unsafe.

Quick start

Three commands

Python 3.12+, a Gemini API key, and you're running.

# Clone the repository
git clone https://github.com/channallikrishnasai/The-Opero.git
cd The-Opero

# Install dependencies
pip install -r requirements.txt

# Add your Gemini API key, then launch
python main.py
