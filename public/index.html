// Automations · real workflows

Speak once.
The loop runs.

Every automation follows the same safe operator pipeline: understand context, choose a supported module, request approval when needed, act, verify, and report.

Morning intelligence briefing

One command compiles your day before you open a tab.

  1. Pull weather, calendar, and top priorities
  2. Summarize unread email themes
  3. Speak and display the executive brief

Inbox triage → reply

  1. Search Gmail for the thread and entities
  2. Draft a confirmation-gated reply
  3. Send only after you approve

Research → report → PDF

Compare products, scrape sources, deliver a formatted file.

  1. Live web research with cited sources
  2. Structure findings into sections
  3. Generate a publication-grade PDF

Organize desktop & downloads

Safe file classification with preview before anything moves.

  1. Dry-run classify incoming files
  2. Show the planned moves
  3. Commit — or full transaction rollback

Deck from a topic

  1. Outline narrative and slide map
  2. Generate .pptx with layout templates
  3. Open the deck for review

Self-heal on runtime error

The operator can repair its own non-core modules.

  1. Capture traceback (protect core files)
  2. Synthesize patch · AST sandbox validate
  3. Atomic backup · apply · auto-rollback if fail

Voice music session

Hands-free playback without leaving your workflow.

  1. Parse play / pause / skip / playlist intent
  2. Drive Spotify or browser player
  3. Confirm state back by voice

System watchtower

Background polling with voice alerts when thresholds break.

  1. Monitor CPU, RAM, battery, processes
  2. Alert on anomaly or non-responsive apps
  3. Offer kill / recover actions
